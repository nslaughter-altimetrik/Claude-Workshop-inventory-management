Architecture Reference

Factory Inventory Management System

A two-tier demo application: a Vue 3 single-page frontend talking to a Python FastAPI backend that serves filtered views over an in-memory JSON dataset. No database, no auth — designed for workshop and prototype use.

System Architecture

Layered view from browser to data files. Each layer talks only to the one beneath it.

Data Flow

How a user-initiated filter change reaches the data files and back.

1

User changes filter

FilterBar component updates a ref in useFilters composable.

2

View reacts

A watch in the active view fires and calls the relevant api.* method.

3

HTTP request

api.js builds URL params and sends an axios GET to :8001/api/*.

4

FastAPI filters

Endpoint runs apply_filters() and (for orders) filter_by_month().

5

Pydantic validates

Result list is serialized through the response_model and returned as JSON.

6

Vue re-renders

Response stored in a ref. Computed properties recalculate. Template updates.
